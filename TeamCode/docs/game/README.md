# BIOBUZZ Game Reference (2026–27)

Short summaries of the **Competition Manual**, so the team (and Claude sessions) can find the key facts
without reading 173 pages. Every fact has a **section and page number** so you can check it.

> ⚠️ **The official manual always wins.** These are summaries and may miss details.
> FIRST publishes **Team Updates (TU)** during the season that can change rules.
> Official manual: <https://ftc-resources.firstinspires.org/ftc/game/manual>
> (HTML version: <https://ftc-resources.firstinspires.org/ftc/game/cm-html/BIOBUZZ%20Competition%20Manual%20-%20TU03.htm>)
